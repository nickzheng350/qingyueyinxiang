## 设计理念

### 色彩系统
- 6大单一色系：天青、木簪、竹黄、琥珀、藕色、水色
- 3大混搭风格：极光（天青+木簪）、星河（竹黄+琥珀）、山水（藕色+水色）

### 模块架构
- 对话（统一入口）
- 记忆（核心差异）
- 技能（能力引擎）
- 插件（扩展体系）
- 工作流（智能编排）
- 模型（API接入）
- 经验库（学习沉淀）
