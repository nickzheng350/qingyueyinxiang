## 六、关于模型测试

**2GB显存 + 24GB内存**的配置分析：

| 模型 | 显存需求 | 是否可行 |
|------|----------|----------|
| SD 1.5 | ~2-4GB | ⚠️ 勉强可行（可能需要启用low-vram模式） |
| SDXL 1.0 | ~8-12GB | ❌ 显存不足 |
| Qwen2.5-7B | ~13-16GB | ❌ 显存不足 |
| 文本模型（小） | ~2-4GB | ⚠️ 勉强可行 |

**建议：**
1. 使用 **SD 1.5** 进行测试（显存占用最低）
2. 启用 **FP16/FP8** 量化模式
3. 使用 **--lowvram** 参数
4. 降低生成分辨率（如 512x512）
