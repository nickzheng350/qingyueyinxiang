## 🚀 快速开始

### 环境要求

- **Python**: 3.10 - 3.13 (推荐 3.12)
- **Node.js**: 16.0 或更高版本
- **操作系统**: Windows / Linux / macOS

### 安装步骤

```bash
# 1. 克隆项目
git clone https://github.com/HydraFlowAI/HydraFlow_AI.git
cd HydraFlow_AI

# 2. 安装依赖
npm install

# 3. 全局链接
npm link

# 4. 一键配置
hydraflow install

# 5. 启动服务
# 终端 1 - API 服务
hydraflow api

# 终端 2 - Web UI
hydraflow ui
```

### 访问地址

- **API 服务**: http://localhost:8000
- **API 文档**: http://localhost:8000/docs
- **Web UI**: http://localhost:3000

### 三层架构

```
┌─────────────────────────────────────────────────────────┐
│                    外部接口层 (API Gateway)              │

└─────────────────────────────────────────────────────────┘
```

### 核心模块

| 模块 | 说明 |
|------|------|
| IntentParser | 意图解析，识别用户需求 |
| ModelDispatcher | 模型调度，分配合适的模型 |
| SkillManager | 技能管理，安装和执行技能 |
| WorkflowEngine | 工作流引擎，执行复杂任务 |

### 安装技能

#### 方式一：命令行安装

```bash
# 搜索技能
python scripts/skill_installer.py search "coding"

# 查看推荐技能
python scripts/skill_installer.py featured

# 从市场安装
python scripts/skill_installer.py install-market hf_llama3_8b

# 从本地路径安装
python scripts/skill_installer.py install-path /path/to/skill
```

#### 方式二：Python API

```python
from src.skills.skill_manager import SkillManager

manager = SkillManager()

# 搜索市场技能
skills = manager.search_market_skills(
    query="stable diffusion",
    category="creative",
    limit=10
)

# 安装技能
result = manager.install_skill_from_market("hf_stable_diffusion_xl")
print(result)

# 从本地安装
result = manager.install_skill_from_path("/path/to/skill", skill_type="local")
```

#### 方式三：直接复制

将技能文件夹复制到 `skills/local/` 目录即可自动加载。

```json
      "enabled": true,
```

## 📡 API 使用

### 解析意图

```bash
curl -X POST http://localhost:8000/api/v1/intent/parse \
  -H "Content-Type: application/json" \
  -d '{"text": "生成一张赛博朋克风格的猫咪图片", "parser": "qwen2.5"}'
```

### 生成图像

```bash
curl -X POST http://localhost:8000/api/v1/generate \
  -H "Content-Type: application/json" \
  -d '{"prompt": "生成一张赛博朋克风格的猫咪图片", "parser": "qwen2.5", "style": "cyberpunk"}'
```

### Python SDK

```python
import requests

api_url = "http://localhost:8000/api/v1"

# 解析意图
response = requests.post(f"{api_url}/intent/parse", json={
    "text": "生成一张图片",
    "parser": "qwen2.5"
})
print(response.json())

# 生成图像
response = requests.post(f"{api_url}/generate", json={
    "prompt": "赛博朋克风格的猫咪",
    "parser": "qwen2.5",
    "style": "cyberpunk"
})
print(response.json())
```


### 重试机制

```python
from src.core import get_stability_manager, RetryConfig, RetryStrategy

manager = get_stability_manager()

@manager.retry(
    RetryConfig(
        strategy=RetryStrategy.EXPONENTIAL_BACKOFF,
        max_attempts=3,
        initial_delay=1.0
    )
)

    # 可能失败的操作
    pass
```

## 🐛 故障排除

### 常见问题

#### 1. Node.js 未找到
```bash
# Windows
winget install OpenJS.NodeJS

# macOS
brew install node

# Linux
sudo apt install nodejs npm
```

#### 2. Python 版本错误
```bash
# 检查版本
python --version

# 需要 Python 3.10-3.13
```

#### 3. 端口被占用
```bash
# 查看端口占用
netstat -ano | findstr :8000

# 使用其他端口
hydraflow api --port 8080
```

#### 4. Git 未安装
```bash
# Windows
winget install Git.Git

# macOS
brew install git

# Linux
sudo apt install git
```

### 日志位置

| 类型 | 路径 |
|------|------|
| 系统日志 | `./logs/` |
| 错误日志 | `./logs/errors.log` |

| 技能缓存 | `./.market_cache/` |

### 诊断命令

```bash
# 检查环境
```
