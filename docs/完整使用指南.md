## 🚀 快速开始

### 环境要求

- **Python**: 3.10 - 3.13 (推荐 3.12)
- **Node.js**: 16.0 或更高版本
- **操作系统**: Windows / Linux / macOS

### 安装步骤

```bash
# 1. 克隆项目
git clone https://github.com/HydraFlowAI/HydraFlow_AI.git
cd HydraFlow_AI

# 2. 安装依赖
npm install

# 3. 全局链接
npm link

# 4. 一键配置
hydraflow install

# 5. 启动服务
# 终端 1 - API 服务
hydraflow api

# 终端 2 - Web UI
hydraflow ui
```

### 访问地址

- **API 服务**: http://localhost:8000
- **API 文档**: http://localhost:8000/docs
- **Web UI**: http://localhost:3000

### 不合理效能消耗优化

#### 问题1: 意图解析过度依赖LLM

```python
# 优化前: 所有查询都调用LLM
def parse_intent(text):
    return llm_api.call(text)  # 每次都调用LLM，耗时且浪费资源

# 优化后: 关键词优先+复杂度分析
def parse_intent(text):
    complexity = analyze_query_complexity(text)
    if complexity < THRESHOLD:
        return keyword_based_parse(text)  # 简单查询用关键词，速度快
    return llm_api.call(text)  # 复杂查询才用LLM
```

**优化效果:**
- 简单查询响应时间从 ~200ms 降至 ~0.2ms（**1000倍加速**）
- 减少90%以上的LLM调用次数
- 显著降低显存和内存占用

**配置选项:**
```json
{
  "intent_parser": {
    "use_llm": true,
    "llm_threshold": "medium",
    "enable_cache": true,
    "cache_ttl": 3600
  }
}
```

| 配置项 | 说明 | 推荐值 |
|--------|------|--------|
| use_llm | 是否启用LLM辅助解析 | true |
| llm_threshold | LLM触发阈值 | medium |
| enable_cache | 启用结果缓存 | true |
| cache_ttl | 缓存有效期(秒) | 3600 |

#### 问题2: 模型重复加载
```python
# 优化前: 每次请求重新加载模型
def process_request(text):
    model = load_model()  # 耗时操作
    return model.generate(text)

# 优化后: 单例模式，模型只加载一次
class ModelSingleton:
    _instance = None
    
    @classmethod
    def get_instance(cls):
        if cls._instance is None:
            cls._instance = load_model()
        return cls._instance
```

#### 问题3: 无限制的并发请求
```python
# 优化前: 无限制并发
@app.post("/generate")
async def generate(request):
    return await model.generate(request.text)

# 优化后: 限制并发数
from fastapi import HTTPException, BackgroundTasks
from asyncio import Semaphore

semaphore = Semaphore(2)  # 限制2个并发请求

@app.post("/generate")
async def generate(request):
    async with semaphore:
        return await model.generate(request.text)
```

#### 问题4: 未使用缓存
```python
# 优化前: 相同请求重复计算
async def parse_intent(text):
    return await llm_api.call(text)

# 优化后: 使用缓存
@cache.cacheable(ttl=3600)
async def parse_intent(text):
    return await llm_api.call(text)
```

#### 问题5: 大文件无流式传输
```python
# 优化前: 一次性加载大文件
async def download_file(url):
    response = requests.get(url)
    return response.content

# 优化后: 流式传输
async def download_file(url):
    response = requests.get(url, stream=True)
    for chunk in response.iter_content(chunk_size=1024):
        yield chunk
```

## 📡 API 使用

### 解析意图

```bash
curl -X POST http://localhost:8002/api/v1/intent/parse \
  -H "Content-Type: application/json" \
  -d '{"text": "生成一张赛博朋克风格的猫咪图片", "parser": "qwen2.5"}'
```

### 增强提示词

```bash
curl -X POST http://localhost:8002/api/v1/intent/enhance \
  -H "Content-Type: application/json" \
  -d '{"prompt": "猫咪", "parser": "qwen2.5", "style": "cyberpunk"}'
```

### 提交任务

```bash
curl -X POST http://localhost:8002/api/v1/tasks \
  -H "Content-Type: application/json" \
  -d '{
    "task_type": "image_generation",
    "prompt": "赛博朋克风格的猫咪",
    "model_id": "sd_1.5"
  }'
```

### Python SDK

```python
import requests

api_url = "http://localhost:8002/api/v1"

# 解析意图
response = requests.post(f"{api_url}/intent/parse", json={
    "text": "生成一张图片",
    "parser": "qwen2.5"
})
print(response.json())

# 增强提示词
response = requests.post(f"{api_url}/intent/enhance", json={
    "prompt": "猫咪",
    "parser": "qwen2.5",
    "style": "cyberpunk"
})
print(response.json())

# 提交任务
response = requests.post(f"{api_url}/tasks", json={
    "task_type": "image_generation",
    "prompt": "赛博朋克风格的猫咪",
    "model_id": "sd_1.5"
})
print(response.json())
```
