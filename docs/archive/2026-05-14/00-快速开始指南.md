## 🚀 超级快速开始（3步搞定）

### 前置要求
- **Node.js**: 16.0 或更高版本
- **Python**: 3.10 - 3.13 (推荐 3.12)

### 1. 安装
```bash
# 克隆或下载项目后，进入项目目录
npm install
```

### 2. 一键配置
```bash
# 全局安装（可选，推荐）
npm link

# 一键安装所有依赖
hydraflow install
```

### 3. 启动服务
```bash
# 终端 1 - 启动 API
hydraflow api

# 终端 2 - 启动 UI
hydraflow ui
```

**访问地址**:
- API 服务: http://localhost:8000
- API 文档: http://localhost:8000/docs
- Web UI: http://localhost:3000

## 💡 详细安装步骤

### 方式一：npm 全局安装（推荐）

#### 1. 获取项目
```bash
# 克隆项目
git clone https://github.com/HydraFlowAI/HydraFlow_AI.git
cd HydraFlow_AI

# 或下载 ZIP 并解压
```

#### 2. 安装 Node.js 依赖
```bash
npm install
```

#### 3. 全局链接（可选但推荐）
```bash
npm link
```
这样就可以在任何目录直接使用 `hydraflow` 命令了。

#### 4. 一键安装所有依赖
```bash
hydraflow install
```
这个命令会自动：
- ✅ 检查 Node.js 和 Python 环境
- ✅ 创建必要的目录
- ✅ 创建 .env 配置文件
- ✅ 安装 Node.js 依赖
- ✅ 安装 Python 依赖

### 方式二：使用 npx（无需全局安装）

如果不想全局安装，可以使用 `npx` 运行：

```bash
# 安装依赖
npm install

# 使用 npx 运行
npx hydraflow install
npx hydraflow check
npx hydraflow api
```

## 🎮 命令列表

### 核心命令

| 命令 | 说明 |
|------|------|
| `hydraflow install` | 一键安装所有依赖并配置项目 |
| `hydraflow check` | 检查环境和依赖 |
| `hydraflow api` | 启动 API 服务 |
| `hydraflow ui` | 启动 UI 服务 |
| `hydraflow dev` | 开发模式启动 |
| `hydraflow install-python` | 仅安装 Python 依赖 |
| `hydraflow install-deps` | 安装所有依赖 |
| `hydraflow --help` | 显示帮助信息 |

### 命令详情

#### 1. 一键安装
```bash
hydraflow install
```
全自动安装和配置，推荐首次使用。

#### 2. 环境检查
```bash
hydraflow check
```
检查 Node.js、Python 和项目文件是否正确。

#### 3. 启动 API 服务
```bash
# 默认端口 8000
hydraflow api

# 自定义端口
hydraflow api --port 8080

# 自定义主机
hydraflow api --host 192.168.1.100

# 开发模式（热重载）
hydraflow api --reload
```

#### 4. 启动 UI 服务
```bash
# 默认端口 3000
hydraflow ui

# 自定义端口
hydraflow ui --port 3001

# 自定义 API 地址
hydraflow ui --api-url http://localhost:8080
```

#### 5. 开发模式
```bash
hydraflow dev
```
提供交互式选择，启动 API 或 UI 的开发模式。

## 📖 使用指南

### 通过 Web UI 使用

1. **启动服务**（需要两个终端）：
   ```bash
   # 终端 1 - 启动 API
   hydraflow api
   
   # 终端 2 - 启动 UI
   hydraflow ui
   ```

2. **访问 UI**: 打开浏览器访问 http://localhost:3000

3. **功能页面**:
   - **主页**: 输入提示词，选择解析器和风格，点击生成按钮
   - **工作流管理**: 创建、执行、删除工作流
   - **模型管理**: 添加、加载、卸载模型
   - **系统信息**: 查看系统状态和统计数据
   - **设置**: 配置系统参数、API设置、模型设置

### 通过 API 使用

#### 解析意图
```bash
curl -X POST http://localhost:8000/api/v1/intent/parse \
  -H "Content-Type: application/json" \
  -d '{"text": "生成一张赛博朋克风格的猫咪图片", "parser": "qwen2.5"}'
```

#### 生成图像
```bash
curl -X POST http://localhost:8000/api/v1/generate \
  -H "Content-Type: application/json" \
  -d '{"prompt": "生成一张赛博朋克风格的猫咪图片", "parser": "qwen2.5", "style": "cyberpunk"}'
```

## 🐛 常见问题

### 1. Node.js 未找到
**原因**: Node.js 未安装或未添加到 PATH
**解决**: 从 https://nodejs.org/ 下载并安装 Node.js 16+

### 2. Python 未找到
**原因**: Python 未安装或未添加到 PATH
**解决**: 从 https://www.python.org/downloads/ 下载并安装 Python 3.10+

### 3. npm install 失败
**原因**: 网络问题或权限问题
**解决**:
- 检查网络连接
- 使用国内镜像: `npm config set registry https://registry.npmmirror.com`
- Windows: 以管理员身份运行
- Linux/macOS: 使用 sudo 或配置 npm 到用户目录

### 4. pip install 失败
**原因**: 网络问题或权限问题
**解决**:
- 检查网络连接
- 使用国内镜像: `pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple`
- Windows: 以管理员身份运行
- Linux/macOS: 使用 --user 选项或虚拟环境

### 5. hydraflow 命令未找到
**原因**: 未执行 `npm link` 或未在项目目录
**解决**:
- 在项目目录运行: `npm link`
- 或使用: `npx hydraflow <command>`

### 6. 端口被占用
**原因**: 端口已被其他程序使用
**解决**:
- 查找占用端口的程序并关闭
- 使用 `--port` 选项指定其他端口

### 7. API 服务启动失败
**原因**: 依赖缺失或配置错误
**解决**:
- 运行 `hydraflow check` 检查环境
- 运行 `hydraflow install` 重新安装依赖
- 检查 .env 配置文件
